# 공공기관 채용 스캐너

잡알리오 오픈API에서 채용공고를 받아 **관심 기관·직무만 걸러 오프라인 HTML**로 만듭니다.
실행할 때마다 지난번과 비교해 **새로 올라온 공고에 NEW 배지**를 붙이고, 마감 임박 순으로 정렬합니다.

## 1. 인증키 준비 (한 번만)

data.go.kr 인증키는 **계정당 하나**이고 승인받은 모든 API에 공용으로 씁니다.
예전에 온비드 API를 쓰면서 발급받은 키(`fa38ec73…`)가 있다면 **새로 발급받을 필요 없이
이 서비스만 활용신청**하면 그 키가 그대로 먹습니다.

1. [공공데이터포털 – 재정경제부_공공기관 채용정보 조회서비스](https://www.data.go.kr/data/15125273/openapi.do) 접속
2. 로그인 → **활용신청** (개발계정은 자동승인, 무료, 일 1,000건)
3. 마이페이지 → 개발계정 → **일반 인증키(Decoding)** 복사
   - Encoding 키가 아니라 **Decoding 키**입니다. `%2F` 같은 게 안 보이는 쪽이 Decoding입니다.
4. `config.json` 을 메모장으로 열어 `serviceKey` 에 붙여넣기

> 신청 직후에는 키가 서버에 반영되기까지 몇 분~1시간 걸립니다.
> 바로 실행하면 `SERVICE_KEY_IS_NOT_REGISTERED_ERROR` 가 뜨는데 정상입니다. 조금 뒤 다시 실행하세요.

## 2. 실행

`RUN.bat` 더블클릭. 끝나면 `채용공고.html` 이 자동으로 열립니다.

바탕화면에서 쓰려면 `RUN.bat` 우클릭 → 바로 가기 만들기.

## 3. 자격증 고르기 — 핵심 기능

HTML 상단 패널에서 자격증 칩을 누릅니다.

```
안 누름 → 보유 → 취득예정 → 안 누름 …
```

37개 자격증이 7개 그룹(안전 / 위험물·화공 / 환경 / 기계·에너지 / 전기·정보 /
토목·건축 / 사무·공통)으로 있습니다. 고르면 **즉시** 목록이 다시 정렬됩니다.
선택은 브라우저에 저장돼서 다음에 열어도 그대로고, `기본값으로` 버튼을 누르면
`config.json` 의 목록으로 돌아갑니다.

### 배지 읽는 법 — 중요

| 배지 | 뜻 | 신뢰도 |
|---|---|---|
| **진한 초록 · 공고에 명시** | 공고 본문에 그 자격증 이름이 실제로 적혀 있음 | 확실 |
| 연한 초록 · 직무 적합 | NCS 직무·제목으로 추정 | 원문 확인 필요 |
| 주황 | 취득예정으로 고른 자격증이 맞은 것 | 참고 |

**대부분의 공고는 자격 요건을 첨부 PDF/HWP로 넘깁니다.** 그래서 '공고에 명시'가
안 뜬다고 해서 그 자격증을 안 본다는 뜻이 아닙니다. 반대로 뜨면 확실합니다.

### 점수 계산

- 공고에 명시 → 100점
- 제목 낱말 일치 → 낱말당 8점
- NCS 직무 일치 → 12 ÷ √(공고의 NCS 개수). 통합공채처럼 직무를 여러 개 붙인
  공고는 그만큼 희석됩니다
- 관심 기관이면 공고당 +15점
- 취득예정은 위 점수의 40%만 반영

## 4. 필터 고치기

`config.json` 만 수정하면 됩니다.

| 항목 | 뜻 |
|---|---|
| `보유자격증` | HTML을 열었을 때 처음 켜져 있을 자격증. 이름은 `certs.py` 와 정확히 같아야 함 |
| `취득예정자격증` | 준비 중인 것. 가중치 40% |
| `고용형태` | **정확히 일치**해야 통과. 값: 정규직 / 무기계약직 / 비정규직 / 공무직 / 청년인턴(체험형) / 청년인턴(채용형) |
| `채용구분` | `신입` 넣으면 "신입"·"신입+경력" 둘 다 통과, "경력"만인 건 탈락 |
| `관심기관` | 기관명 일부. 걸리면 '관심 기관' 태그 |
| `제외키워드` | 제목이나 기관명에 있으면 버림 |
| `근무지역` | 비우면 전국. 예: `["서울","경기","인천"]` |

기본값(정규직·무기계약직 / 신입 포함)으로 **진행중 492건 → 50건**이 HTML에 실립니다.
자격증 필터는 브라우저에서 걸리므로, 결과가 적으면 재실행 없이 화면에서 바로 조정하세요.
그래도 부족하면 `채용구분`을 비우거나 `제외키워드`를 줄이고 다시 실행합니다.

## 5. 왜 50건밖에 안 되나

492건이 어디서 깎이는지 실제 수치입니다.

```
492  진행 중 공고
-341  ① 고용형태   비정규직 293 · 체험형인턴 31 · 비정규직+체험형 14
 -19  ② 채용구분   '경력'만 뽑는 공고
 -86  ③ 제외키워드  병원 23 · 의사 19 · 간호 12 · 교수 11 · 조리 5 · 기타
----
  50
```

**잡알리오 진행중 공고의 60%가 비정규직**이고, 제외된 86건 중 **72건이 의료기관**입니다
(국립대병원·의료원이 전부 공공기관이라 간호사·전공의 공고가 대량으로 올라옵니다).
줄어든 게 아니라 공공기관 정규직 신입 공채 모수가 원래 이 정도입니다.

더 보고 싶으면 `config.json` 에서:

- `"채용구분": []` — 경력 공고까지 (+19건). 경력 1~2년만 요구하는 공고도 있습니다
- `"고용형태"` 에 `"비정규직"` 추가 — 계약직까지 (+293건, 대부분 단기)
- `제외키워드` 에서 `"병원"`·`"간호"` 빼기 — 의료기관까지

## 6. 만든 HTML 보는 법

상단 버튼으로 걸러 봅니다 — **전체 / 새 공고 / 마감 10일 이내 / 관심 기관 / 자격증 언급**.
왼쪽 D-day 색이 빨강이면 3일 이내, 주황이면 10일 이내입니다.

## 명령어

```
RUN.bat              평소 실행
RUN.bat --all        필터 없이 진행 중인 공고 전부
RUN.bat --dump       원본 JSON 첫 건과 필드명 출력
RUN.bat --salary     보수 정보를 강제로 다시 받기 (기본은 30일 캐시)

python app.py        서버 모드로 띄우기 (SERVICE_KEY 환경변수 필요)
```

`--dump` 는 API 응답 필드명이 바뀌었을 때 확인용입니다. 출력된 필드명이
`scan.py` 의 `norm()` 함수에 적힌 이름과 다르면 거기만 고치면 됩니다.

## 한계 — 이걸로 안 되는 것

이 API는 **공고 메타정보**만 줍니다. 다음은 들어 있지 않습니다.

- **경쟁률** — 공공기관은 지원자 수를 공시하지 않습니다
- **자격증 가점표** — 공고 첨부 PDF/HWP 안에 있고, API는 첨부파일 메타정보만 줍니다
- **합격 커트라인** — 공식 데이터 자체가 없습니다
- **지방공기업** — 지자체 환경공단·시설관리공단은 [클린아이 잡플러스](https://job.cleaneye.go.kr)
  소관인데 공식 오픈API가 없습니다. 그쪽은 사이트를 직접 봐야 합니다.

## 8. 클라우드타입에 올리기

로컬에서는 `RUN.bat` 이 HTML 을 만들고 브라우저를 띄우지만, 서버에서는 `app.py` 가
그 자리를 대신합니다. 뜨자마자 목록을 한 번 만들고, 정해진 주기로 다시 만들고,
만들어진 HTML 을 그대로 서빙합니다. **외부 패키지는 하나도 쓰지 않습니다.**

### 클라우드타입 설정

1. [cloudtype.io](https://cloudtype.io) 로그인 → **새 프로젝트** → 이 깃허브 저장소 선택
2. 템플릿은 **Python** 선택
3. 설정값

   | 항목 | 값 |
   |---|---|
   | 시작 명령어 | `python app.py` |
   | 포트 | `8080` |

4. **환경변수**에 인증키를 넣습니다 (이게 제일 중요합니다)

   | 이름 | 값 |
   |---|---|
   | `SERVICE_KEY` | data.go.kr 일반 인증키(Decoding) |
   | `TZ` | `Asia/Seoul` (선택 — 코드가 이미 KST 로 고정하므로 로그만 예뻐집니다) |
   | `REFRESH_HOURS` | 갱신 주기, 기본 `6` |
   | `REBUILD_TOKEN` | 아무 문자열. 넣으면 수동 갱신 주소가 열립니다 |

5. 배포 후 접속. 첫 화면이 "목록을 아직 만들지 못했습니다" 면 20초쯤 뒤 새로고침하세요.

### 주소

```
/                   채용공고 목록
/health             상태 확인 (ok N건)
/rebuild?token=...  수동 갱신 (REBUILD_TOKEN 을 넣었을 때만)
```

### 인증키는 저장소에 없습니다

`config.json` 은 `.gitignore` 에 들어 있어 깃허브에 올라가지 않습니다.
대신 키를 뺀 `config.sample.json` 이 올라가고, 서버는 `SERVICE_KEY` 환경변수에서
키를 읽습니다. **환경변수가 `config.json` 보다 우선**이라 로컬 파일은 건드릴 필요가 없습니다.

필터(관심기관·제외키워드 등)를 서버에서 바꾸려면 `config.sample.json` 을 고쳐
커밋하면 다시 배포됩니다.

### 주의

- 공공데이터포털 개발계정은 **하루 1,000회** 제한입니다. 한 번 갱신에 5회쯤 쓰므로
  기본 6시간 주기(하루 4회 ≒ 20회)면 넉넉합니다. 주기를 1시간 밑으로 내리지 마세요.
- 클라우드타입 컨테이너는 재시작하면 디스크가 초기화됩니다. `seen.json` 이 날아가
  재시작 직후 한 번은 NEW 배지가 안 붙습니다. 목록 자체는 정상입니다.
- 컨테이너 시계는 UTC 라 D-day 가 하루 밀릴 수 있어, 코드에서 KST 로 고정해 뒀습니다.

## 파일

```
scan.py             본체 (목록 생성)
salary.py           알리오 경영공시에서 기관별 보수 가져오기
compete.py          마감된 공고에서 기관별 과거 경쟁률 모으기
certs.py            자격증 사전 (37개, 이름·NCS직무·제목낱말)
app.py              서버용 진입점 (클라우드타입)
config.json         인증키와 필터 — 로컬 전용, 깃허브에 안 올라감
config.sample.json  키를 뺀 같은 설정 — 배포본이 이걸 씁니다
requirements.txt    비어 있음 (표준 라이브러리만 사용)
RUN.bat             로컬 실행
seen.json           지난 실행에서 본 공고 번호 (NEW 판정용, 자동 생성)
salary.json         보수 정보 캐시 (30일, 자동 생성)
compete.json        과거 경쟁률 표본 (하루 200회씩 누적, 자동 생성)
채용공고.html        결과 (자동 생성)
```

`seen.json` 을 지우면 다음 실행이 '첫 실행'으로 취급되어 NEW 배지가 안 붙습니다.
